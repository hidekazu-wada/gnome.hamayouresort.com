# 繋ぎ波の画像に書き出し不良があります（再書き出しのお願い）

作成: 2026-08-06 ／ 対象: 繋ぎ波の WEBP 25枚のうち **18枚**

## 何が起きているか

セクションとセクションの間に入る繋ぎ波の画像で、**本来なら不透明であるべき帯の途中に
半透明の行が混ざっています**。そこだけ下地が透けるため、波の上や下に**細い明るい線**が
見えます。

修正リストに上がっている次の項目は、すべてこれが原因です。

- 泊まる詳細「ホテルセットプランの下に下線が表示されてしまっている」（PC / TB / SP）
- 泊まる詳細「料金の上に下線が表示されてしまっている」（PC / TB / SP）

## ブラウザによって出たり出なかったりする理由

画像は表示時に縮小されます。半透明の行が縮小後の実ピクセルに乗るかどうかが
**ブラウザの補間方法によって変わる**ため、「Safari では出るが Chrome では出ない」
「TB では出るが PC では出ない」といったばらつきになります。
**画像自体はどの環境でも同じように壊れています。**

## 実例

`stay/detail/wave-to-notes-sp.webp`（1440x460）の上から75%あたり

```
  行343   alpha 237
  行344   alpha 206
  行345   alpha 156   ← ここだけ61%しか不透明でない
  行346   alpha 249
  行347   alpha 255
```

前後は不透明なのに、この行だけ透けています。

## お願いしたいこと

**元データ（Figma等）からの再書き出し**をお願いします。こちらで画素を補修することも
検討しましたが、波の輪郭のアンチエイリアスと欠けの区別が画像ごとに異なり、
安全に自動処理できませんでした。**書き出し元を直すのが確実です。**

書き出し時のご確認ポイント:

- 波の帯の内部が**全行 alpha 255** になっていること（輪郭のぼかしは残して問題ありません）
- 複数の図形を重ねている場合、**重なりの継ぎ目に隙間ができていないか**
- 書き出し倍率を変えても継ぎ目が出ないこと

## 確認方法

差し替えが届いたら、リポジトリで次を実行すると欠けの有無を判定できます。

```
node scripts/check-wave-alpha.mjs
```

すべて `○ 欠けなし` になれば解消です。
